# Minions Test-scenarios

Conversation scripts, tester personas, edge cases, and golden datasets

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-test-scenarios/sdk`) — Core library for Node.js
- **Python SDK** (`minions-test-scenarios`) — Python bindings
- **CLI Tool** (`@minions-test-scenarios/cli`) — Command-line interface
- **Web App** — Interactive playground at [test-scenarios.minions.wtf](https://test-scenarios.minions.wtf)
