---
title: Installation
description: Install Minions Test-scenarios packages
---

## TypeScript / Node.js

```bash
npm install @minions-test-scenarios/sdk minions-sdk
```

## Python

```bash
pip install minions-test-scenarios
```

## CLI

```bash
npm install -g @minions-test-scenarios/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
