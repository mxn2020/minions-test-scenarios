# Welcome to Minions Test-scenarios

We're excited to introduce **Minions Test-scenarios** — Conversation scripts, tester personas, edge cases, and golden datasets.

## What's Included

- **TypeScript SDK**: `npm install @minions-test-scenarios/sdk`
- **Python SDK**: `pip install minions-test-scenarios`
- **CLI**: `npm install -g @minions-test-scenarios/cli`
